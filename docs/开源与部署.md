# ChatArchive 开源与部署

当前为 MIT 许可的查询预览版，包含 Python 后台、界面、HTTP/MCP、虚构示例与部署文件。功能及启动命令见 [README](../README.md)，现有部署边界见 [部署](DEPLOYMENT.md)。

本地管理员登录已实现；分级成员权限、原始归档、清洗重放与连接管理见 [服务器架构](架构与接口草案.md)。这些是目标设计，尚未全部实现。正式发布条件见 [实施清单](实施清单.md)。

## 公开内容

源码包仅包含显式允许的程序、虚构样例及演示截图、测试和公开文档。内部盘点、生产截图、真实聊天、数据库、附件、静态数据快照、凭据、服务器发布脚本和厂商二进制 SDK 不进入公开包。忽略规则不能替代实际打包检查。

不要将整个工作目录推到公开仓库。从审核后的源码包建立干净仓库，再运行测试、检查敏感信息和第三方许可。各平台授权由部署者提供，项目不提供共享企业账号或现成聊天库。

贡献流程见 [CONTRIBUTING](../CONTRIBUTING.md)，安全边界见 [SECURITY](../SECURITY.md)，版本状态见 [CHANGELOG](../CHANGELOG.md)。官方仓库为 [daqianwenlv/ChatArchive](https://github.com/daqianwenlv/ChatArchive)，私密报告方式见 SECURITY。

## 独立运行与平台接入

独立部署运行后台并管理自己的数据和权限。外部平台通过 HTTP 或 MCP 调用同一服务，客户端配置仅指向已有后台，不复制后台或管理员权限。

当前接入要求客户端能配置 Bearer 请求头，OAuth 授权发现尚未实现。Python 与 Linux amd64 容器安装均已实测，具体环境和网络条件见 [验证记录](VALIDATION.md)。生产部署、源码公开和托管服务上线分别验收，不能互相替代。
