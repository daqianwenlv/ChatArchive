# ChatArchive 实施与发布清单

[English](ROADMAP.en.md) · **简体中文**

当前为 0.4 归档与任务预览版。架构可供公开评审，程序应按已实现功能发布预览，不能描述为完成了多用户、原始归档或托管 SaaS。架构整理和源码打包不代表下列开发项目已经完成。

## 已实现

- [x] 概览、数据源、指令台、任务、MCP 接口五个入口，真实群目录、正文与统计。
- [x] 跨群规则统计、日/周/月计划、结果快照与 CSV/Markdown/JSON 导出；备份恢复后暂停计划。
- [x] 读取既有飞书归档、企业微信存档、微信历史；纳入多个飞书 CLI 连接的可见群目录。
- [x] 私有 SQLite 快照和原子替换，失败保留前一版本。
- [x] HTTP 与五个只读 MCP 工具复用查询权限。
- [x] 平台、群、工具权限和期限限定的密钥、撤销与调用审计。
- [x] Python 初始化、虚构数据导入、源码打包和自动化测试。
- [x] MIT 许可证、环境模板、容器与 systemd 文件。
- [x] 实际 HTTPS MCP 初始化、工具发现、消息查询、越权拒绝与撤销验证。
- [x] 本地管理员账号、首次改密、服务端会话、轮换撤销、登录限速与来源校验。
- [x] SQLite 快照备份、SHA-256 校验、新目录恢复、凭据作废和恢复后密码重设。
- [x] 可复现源码包、发布内容检查、虚构样例、MCP SDK 客户端示例与 CI 配置。

本版实测环境与结果见 [验证记录](VALIDATION.md)，容器验收使用 `scripts/verify_docker.py`。仅可见但无记录的群仍需配置采集。钉钉和个人微信实时采集未实现。

## 阶段一 原始归档与领域模型

- [ ] 工作空间、连接实例、原始对象目录、事件、消息与版本模型。
- [ ] PostgreSQL 与版本化迁移，私有文件存储接口和本地实现。
- [ ] 原始对象耐久写入，目录、持久任务和采集游标在同一数据库事务提交。
- [ ] 任务租约、心跳、重试、分区互斥、孤立对象核对。
- [ ] 旧记录标注原始报文、标准导出或不完整历史，不补造字段。
- [ ] 重复导入不新增逻辑消息；各来源独立推进，失败显示旧数据与延迟。

验收：故障注入覆盖写对象前后、数据库提交前后和任务中断；计数可解释；已提交游标对应的原始对象可校验；旧系统保持可回退。

## 阶段二 用户与授权

- [ ] 一次性安装引导、所有者、邀请、退出、停用和恢复路径。
- [ ] 企业身份适配与可选本地账号；登录身份与采集令牌分离。
- [x] 服务端会话、轮换撤销、登录限流、CSRF 和安全 cookie。
- [ ] 角色与连接、群范围控制；正文、统计、原始负载、导出分开授权。
- [ ] 服务账号不可扩大可授予权限，成员停用后访问和排队任务失效。
- [ ] 数据库、文件、缓存、分析结果与任务的跨工作空间隔离。

验收：两个工作空间、同名用户和不同群权限参与端到端测试；页面、HTTP、MCP、文件和统计均不可越权；撤销与停用影响新的请求。

## 阶段三 清洗与连接管理

- [ ] 连接创建、主体校验、群发现、采集选择、历史起点、暂停和补采。
- [ ] 凭据加密、轮换、配置检查，不回显已保存凭据。
- [ ] 内容块、原时间与 UTC、类型映射、名称历史。
- [ ] 重复、编辑、撤回、多机器人合并和冲突版本处理。
- [ ] 清洗版本、隔离区、重放、差异对账、服务视图切换与回退。
- [ ] 附件原件与独立下载状态；OCR、转写与模型作为可选派生任务。
- [ ] 连接状态、最近成功采集、处理延迟和不可恢复缺口可见。

验收：飞书和企业微信各一套授权样本完成原始归档、标准化、查询及来源回溯；畸形负载、缺日期、同名账号和撤回有解释；重放不覆盖原件。

## 正式发布门槛

- [ ] 干净环境不依赖私有配置，完成安装、登录、导入、HTTP/MCP 和升级。
- [ ] Docker 构建、持久卷重建、数据库迁移和回退经过实际验证。
- [ ] 数据库、对象、配置和密钥恢复演练；删除清单恢复后继续生效。
- [ ] 保留策略、磁盘不足、写满和失败重试有明确行为。
- [ ] 通用代码去掉旧系统固定目录与业务标签，历史桥接适配器具名并可配置。
- [ ] 审核第三方许可证、依赖清单、漏洞和敏感信息扫描，处理阻断项。
- [ ] 登录、授权和导出经过独立安全复核；测试通过不等于安全审计。
- [ ] 记录目标数据规模和并发下的导入、查询延迟、CPU、内存及存储占用。
- [x] 官方 MCP Python SDK 已完成真实 HTTP 端点调用，记录 Bearer 授权方式和兼容边界。
- [ ] 发布说明、升级说明、已知限制、维护与私密安全报告渠道齐备。

首次公开可以是明确标识的查询预览版；完整归档服务或正式企业版需完成相应门槛。官方仓库为 [daqianwenlv/ChatArchive](https://github.com/daqianwenlv/ChatArchive)，安全报告方式见 [SECURITY](../SECURITY.md)。

## 后续扩展

按需求增加 S3 存储实现、OAuth 客户端授权发现、更大范围的内容分析、完整归档导出、设备代理和钉钉连接器。功能分别验收，页面占位不代表实现。跨企业托管服务另行验证隔离、容量、恢复和运营能力。
