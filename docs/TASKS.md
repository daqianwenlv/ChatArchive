# 指令台与任务

[English](TASKS.en.md) · **简体中文**

在「指令台」选择群、消息类型、正文关键词、时间范围、统计方式和导出格式。点击「立即统计」生成一次运行；填写名称和周期后，「保存为任务」会保存规则并安排未来执行。保存不会立即生成报告。

例如：选中产品群和交付群，统计前 7 个完整自然日的文件消息，整理资料清单，每周一 09:00 执行，结果导出为 CSV。群可以来自不同数据源，无名称的群使用编号。

## 行为

- 统计方式：按群、按日期、按发送者、按消息类型汇总，或整理消息资料清单。
- 时间范围：前 N 个完整自然日（不含当天），或截至执行参考时刻的最近 N 天。按任务时区计算，结果明确记录包含开始、不含结束的时间范围。
- 日/周/月计划按任务的 IANA 时区执行；每月可选 1–28 日。夏令时跳过不存在的时刻，回拨时仅执行第一次。
- 任务由 API 服务内的后台线程执行，每 15 秒检查一次。多进程通过同一数据目录的主机文件锁串行执行。不支持跨主机共享 SQLite 的调度集群。
- 服务停机后，每个到期任务补一次当前统计窗口；不逐次重放遗漏的周期。崩溃时处于运行中的任务记为失败，可手动重新运行。排队规则与结果均保存在 `tasks.sqlite3`。
- 暂停任务取消尚未开始的定时运行；已经开始的运行和明确发起的手动运行继续完成。启用后从下一个计划时间开始。修改规则不改变已排队或已完成的运行快照。
- 报告保存在工作空间，支持 CSV、Markdown、JSON 下载；不向外部平台发消息。任务数据库纳入备份；恢复后所有计划暂停。

## 统计边界

统计对象是查询索引中的已归档消息。按完整关键词做字面子串匹配，不支持多个词的 OR 表达式，不执行提示词、SQL 或脚本。资料清单包含消息正文摘录和引用；不下载或解析附件，不做模型语义总结，也不根据发言数量给员工打分。

每条规则最多 50 个群、366 天；保存任务最多 200 个；等待和运行队列最多 20 条；同一保存任务不能重复入队。统计在同一个只读索引快照内完成，查询时间上限约 45 秒。总消息数按全部匹配记录计算，结果表格最多 2,000 行；原文依据最多 100 条，每条正文摘录最多 2,000 字。达到上限会明确标记；原文仍可通过消息 ID 查询。

已撤回与无时间记录不参与有时间范围的统计。无时间记录的数量单列，但不能判断其属于哪个统计周期。发送者使用来源和账号编号去重；未知账号不计入参与者总数。不同平台上的同一个人不会自动合并。

运行结果保存时点的快照，后续索引更新不会改写它。结果含聊天资料，沿用私有数据目录保护，仅管理员可查看。当前不自动清理历史运行；部署者需监控数据目录容量。旧版程序不能读取任务备份，恢复时使用本版本或更新版本。

## HTTP 接口

所有路径位于 `/api`，仅管理员账号会话或既有管理员服务凭据可用。受限查询密钥不能读写任务。浏览器写入要求同源 Origin，并记录审计元信息。原有五个 MCP 工具保持只读。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | /commands | 即时统计，返回 202 与运行 ID |
| GET / POST | /tasks | 列表 / 创建规则 |
| GET / PUT | /tasks/{id} | 查询 / 完整更新规则 |
| POST | /tasks/{id}/pause 或 /resume | 暂停 / 启用 |
| POST | /tasks/{id}/run | 手动运行，返回 202 |
| GET | /task-runs?task_id={id}&offset=0 | 运行记录，30 条一页，task_id 可省略 |
| GET | /task-runs/{id} | 状态、规则快照、结果 |
| GET | /task-runs/{id}/export?format=csv | 导出 csv / markdown / json |

创建任务的请求体：

```json
{
  "name": "每周资料汇总",
  "rule": {
    "groups": [{"source": "feishu", "id": "demo-product"}],
    "keyword": "",
    "message_type": "file",
    "days": 7,
    "window": "complete_days",
    "dimension": "records",
    "timezone": "Asia/Shanghai"
  },
  "schedule": {"frequency": "weekly", "time": "09:00", "weekday": 0, "monthday": 1},
  "output": "csv",
  "enabled": true
}
```

`weekday` 的 0–6 对应周一至周日；`frequency` 为 manual/daily/weekly/monthly；`dimension` 为 group/day/sender/type/records；`window` 为 complete_days/rolling。即时统计只提交 name、rule、output。运行状态为 queued、running、succeeded、failed、cancelled；只有成功运行可导出。
